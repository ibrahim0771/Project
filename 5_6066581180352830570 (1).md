\#\# Critical Mistakes to Avoid

| Mistake | Consequence | Fix |

|---|---|---|

| Using \`window.print()\` only | No control over layout, headers | Use Puppeteer backend |

| Hardcoding company data in templates | Can't reuse across clients | Always inject via schema |

| CSS \`px\` units in print templates | Inconsistent across printers | Use \`mm\` / \`pt\` for print |

| No page-break handling | Tables split mid-row on multi-page | Use \`page-break-inside: avoid\` |

| Client-side PDF only | Large documents timeout/crash browser | Always Puppeteer on backend |

| Skipping the base schema | Every template becomes inconsistent | Define base schema first |

| Mixing preview and print styles | Preview looks different from PDF | Use \`@media print\` strictly |
